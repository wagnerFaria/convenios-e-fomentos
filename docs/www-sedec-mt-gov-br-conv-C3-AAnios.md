## CONVÊNIOS

## Termo de Convênio

O Termo de Convênio é o instrumento utilizado para formalizar parcerias entre a SEDEC e outros órgãos ou entidades públicas, como prefeituras e autarquias, para execução de ações de interesse comum.

Aqui você encontra a legislação, os modelos de documentos e as orientações necessárias para celebrar um convênio com a Secretaria de Estado de Desenvolvimento Econômico.

## Checklists e Modelos de Documentos

Documentação exigida para protocolo, separada por tipo de parceiro.

### Lista de Documentos Obrigatórios para Requerimento de Apoio Financeiro para Prefeituras

| Item | Documentos obrigatórios |
| --- | --- |
| 1 | Ofício de solicitação da proposta da Prefeitura para o Secretário(a) da SEDEC. |
| 2 | Requerimento de apoio financeiro. |
| 2.1 | Cópia do ofício da destinação da emenda parlamentar. |
| 2.2 | Cópia do ofício da Casa Civil assinado pelo Secretário. |
| 3 | Plano de Trabalho e anexos do SIGCon. |
| 3.1 | Cadastro de Órgãos ou Entidades e Dirigentes. |
| 3.2 | Dados do Projeto. |
| 3.3 | Cronograma de execução física e Plano de Aplicação de Recursos. |
| 3.4 | Cronograma de Desembolso. |
| 3.5 | Relação de Equipamentos e Materiais Permanentes. |
| 3.6 | Memória de cálculo detalhada emitida pelo SIGCon. |
| 3.7 | Comprovante de envio do Plano de Trabalho no Sistema SIGCon. |
| 4 | Certidão de Habilitação Plena emitida pelo SIGCon. |
| 5 | Termo de Referência. |
| 6 | Declaração de contrapartida. |
| 6.1 | Quadro de Detalhamento de Despesa. |
| 6.2 | Cópia da publicação em Diário Oficial da Lei Orçamentária Anual. |
| 7 | Declaração de compatibilidade de preços. |
| 7.1 | Avaliação de mercado, três orçamentos ou Ata de Registro de Preço. |
| 7.2 | Em caso de exclusividade: três notas fiscais e contrato de exclusividade. |
| 8 | Declaração de não duplicidade de objeto. |
| 9 | Declaração de gratuidade. |
| 10 | Declaração de publicidade de parceria. |
| 11 | Comprovante de equipe técnica com capacidade para executar e prestar contas. |
| 12 | Cópia do comprovante de endereço da Prefeitura. |
| 13 | Cópia do cartão do CNPJ da Prefeitura. |
| 14 | Cópia do RG e CPF do Prefeito. |
| 15 | Cópia da ata de nomeação do Prefeito. |
| 16 | Cópia do diploma da nomeação do Prefeito. |
| 17 | Cópia do comprovante de endereço do Prefeito. |
| 18 | Mapa comparativo dos orçamentos apresentados. |
| 19 | Análise crítica dos orçamentos apresentados. |
| 20 | Justificativa para redução de prazo, quando aplicável. |

### Quando objeto for obra os documentos abaixo deverão ser apresentados

| Item | Documentos obrigatórios |
| --- | --- |
| 21 | Projeto básico da obra ou serviço de engenharia. |
| 21.1 | Projeto arquitetônico executivo. |
| 21.2 | Projeto de instalações elétricas. |
| 21.3 | Projeto de instalações hidrossanitárias. |
| 21.4 | Projeto estrutural. |
| 21.5 | Projeto de climatização, se houver. |
| 21.6 | Projeto de prevenção e combate a incêndio, quando exigido. |
| 21.7 | Projeto de SPDA ou dispensa. |
| 21.8 | Mapa de danos, no caso de restauração. |
| 21.9 | Memorial descritivo dos projetos. |
| 21.10 | Planilha orçamentária. |
| 21.11 | Cronograma físico-financeiro. |
| 21.12 | Anotação de Responsabilidade Técnica — CREA e/ou CAU. |
| 22 | Termo de Referência, quando envolver aquisição de bens ou serviços. |
| 23 | Licenças ambientais ou dispensa delas. |
| 24 | Certificado de propriedade do imóvel. |

### Documentos após análise técnica favorável

| Item | Documentos obrigatórios |
| --- | --- |
| 25 | Declaração de conta bancária específica. |
| 26 | Contrato de abertura de conta corrente específica para o convênio. |
| 27 | Extrato de conta bancária zerada. |
